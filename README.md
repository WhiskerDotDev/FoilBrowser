## Foil Browser

###### Minimal yet Malleable, or so I hope it'll be!

FoilBrowser is a web browser made with QML & C++. It is Chromium-based (thanks to QtWebEngine)

### FEATURES:

- window-wide user-generated shader loading (must be written in GLSL and compiled via QSB)
- Viewport color adjustment of contrast, saturation, brightness, and RGB tint 
- limited use of multi-frame images as assets (I plan to make this the norm for most GUI elements)
- Persistent, file-based flags for Chromium
